This repository is where I document my learning journey as I work toward becoming a better software developer.

My mentor, **Marcio Ferreira**, challenged me to follow a 365-day study roadmap covering a wide range of Computer Science and Software Engineering topics. One of the first tasks he gave me was to create a repository dedicated entirely to this journey.

Here, you'll find my notes, explanations, code examples, exercises, and anything else I study throughout the roadmap. My goal is to build knowledge consistently, strengthen my fundamentals, and keep a record of my progress over time.

This repository isn't meant to be perfect—it's meant to reflect my growth. As I learn, I'll continue improving both my understanding and the content shared here.
